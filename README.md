# Maison Olive

A brand landing page for **Maison Olive** — a Provençal small-batch olive oil
and gourmet boutique.

## What's here

- `index.html` — the single-page site (hero, story, collection, process, visit).
- `styles.css` — all styling. No frameworks, no build step, no dependencies.

## View it

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Notes

The content (varietals, prices, address, founding year) is placeholder copy —
swap it for the real brand details. Product images are CSS gradient
placeholders; replace the `.card-media` blocks with real photography when ready.
